# Mi Coach

App personal de gym (PWA) — HTML + CSS + JS, sin frameworks, datos en el teléfono.

## Cómo correrla en tu Mac

1. Instala [VS Code](https://code.visualstudio.com/).
2. Clona el repo y cambia a la rama:
   ```bash
   git clone https://github.com/despindol/App.git
   cd App
   git checkout claude/mens-wellness-app-ecg21e
   ```
3. Abre `index.html` en Safari o Chrome (doble clic basta).
4. Para ver errores: Safari → Ajustes → Avanzado → "Mostrar funciones para desarrolladores web",
   luego `Opción + Cmd + C` abre la consola.
